# Agent Guidelines: LBC (La Buona Community)

Linee guida per agenti operativi all'interno dell'ecosistema LBC — Ecosistema Economico, Professionale e Territoriale Integrato.

## Agent skills

### Issue tracker

GitHub Issues per `MarioDaeda/lbc-la-buona-community` con supporto locale in `.scratch/`. Vedi `docs/agents/issue-tracker.md`.

### Triage labels

Ruoli standard canonici (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Vedi `docs/agents/triage-labels.md`.

### Domain docs

Layout single-context (`CONTEXT.md` e `docs/adr/`). Vedi `docs/agents/domain.md`.

### Workflow Chiave Disponibili

- `/grill-me`: Intervista per chiarire e validare aspetti contrattuali, societari, strategici o tecnici prima della stesura.
- `/to-spec`: Sintesi di requisiti o accordi in specifiche documentali operative.
- `/to-tickets`: Scomposizione degli sprint di processo o task di sviluppo in ticket autonomi.
- `/implement`: Esecuzione disciplinata dei task specificati.
- `/code-review`: Revisione incrociata di coerenza giuridica/tecnica e aderenza agli standard.
- `/domain-modeling`: Aggiornamento e perfezionamento del vocabolario di distretto e delle decisioni architetturali.
