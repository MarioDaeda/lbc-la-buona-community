# Domain Docs

How the engineering and planning skills consume this repo's domain documentation.

## Before exploring, read these

- **`CONTEXT.md`** at the repo root: essential institutional, corporate and legal glossary.
- **`docs/adr/`**: read architectural/legal decisions that touch the area you are working on.
- **`README.md`**: circular model, dual-entity design, and stakeholder overview.

## Use the glossary's vocabulary

When creating issues, documents, contracts, or specifications, strictly use the terms defined in `CONTEXT.md` (e.g. *Dual-Entity*, *Contratto di Rete*, *Fondo Patrimoniale Comune*, *Sprint 45 Giorni*, *Audit 90 Minuti*, *ETS-APS*). Do not invent generic synonyms.
